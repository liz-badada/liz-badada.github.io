## Reading tiers

Each note is tagged `L1`–`L5`:

- **L1** — aware it exists
- **L2** — abstract + intro + conclusion
- **L3** — full read + key experiments understood
- **L4** — can reproduce key figures / numbers
- **L5** — deeply internalized, applied to own work
